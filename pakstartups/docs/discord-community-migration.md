# Discord Community Migration Strategy & Wind-Down Plan

**Date:** July 26, 2026  
**Status:** Approved  
**Author:** PakStartups Core Engineering & Community Team  

---

## 1. Executive Summary

PakStartups is migrating its real-time community channels from fragmented WhatsApp groups and static forum links to a single, structured, official **Discord Server** (`discord.gg/pakstartups`).

### Primary Objectives
- **Centralize Community Discussions:** Move chaotic WhatsApp messaging into structured, searchable Discord channels.
- **Improved Moderation & Bot Safety:** Enforce auto-moderation rules, spam filtering, and role-based permissions.
- **Source Attribution:** Measure community growth through source-attributed invite links (`?utm_source=website_hero`, `?utm_source=directory`, `?utm_source=events`).

## 2. Discord Channel Architecture

| Category | Channel Name | Description |
| :--- | :--- | :--- |
| **Welcome** | `#rules-and-info` | Server guidelines, code of conduct, and verification steps |
| **Welcome** | `#introductions` | Member intro channel for new founders, developers, and investors |
| **Community** | `#general-tech` | Main discussion on Pakistan's tech ecosystem |
| **Community** | `#find-cofounder` | Real-time networking for technical and business co-founders |
| **Product** | `#b2b-deals` | Claiming startup discounts and B2B provider discussions |
| **Product** | `#events-and-meetups` | Announcements for upcoming hackathons, webinars, and meetups |
| **Support** | `#support-tickets` | Bot-facilitated support ticket creation |

---

## 3. WhatsApp Wind-Down & Migration Timeline

1. **Phase 1 (Week 1):** Publish migration announcement across all active WhatsApp groups and pin Discord invite link.
2. **Phase 2 (Week 2-3):** Mute general messaging on WhatsApp groups; convert groups to announcement-only broadcast channels.
3. **Phase 3 (Week 4):** Permanently redirect all WhatsApp descriptions and website links to `discord.gg/pakstartups`.
